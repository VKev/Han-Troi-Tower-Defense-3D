# TowerDefense3D Web Prototypes

## Current — Projectile Network TD: Cóc Kiện Trời

The current Three.js/Vite prototype lives in [`Projectile-Network-TD/`](Projectile-Network-TD/). It implements the Link network, three-level drought campaign, Vietnamese text-free onboarding gestures, elemental reactions, the frog tongue attack, and responsive desktop/mobile controls.

Level 1 labels `Lò Đạn` as `ĐẦU` and `Trống Mưa` as `CUỐI`, then confirms each completed route with a two-pass gold/rain-blue LED packet without brightening or revealing its link beams. Both endpoint labels turn green only while the full directed route remains valid; every completion or breakage color change pulses them once before settling. Linking starts by dragging directly from a tower, without a preselection click. The authored Băng lesson cell now appears directly below Lò Đạn in the default camera, separating the `Hỏa → Băng` route from `Lò Đạn → Hỏa`. Enemy trails use their authored terrain shape without a separate direction arrow.

Production: [https://projectile-network-td-soul.vercel.app](https://projectile-network-td-soul.vercel.app)
